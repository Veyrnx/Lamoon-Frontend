# เริ่มเชื่อม Ordering กับ Supabase

## สิ่งที่เปลี่ยนในแพตช์นี้
- เพิ่มการอ่านรายการสินค้าจาก `public.products` ผ่าน Supabase
- ปรับขนาดตัวอักษรและหัวข้อให้กะทัดรัดขึ้น อ่านแยกส่วนได้ง่ายขึ้น
- กดโปรโมชันเดิมซ้ำเพื่อยกเลิกได้ และกดโปรโมชันอื่นเพื่อเปลี่ยนส่วนลด
- แสดงสถานะการเชื่อมต่อ/ข้อความ error ในส่วนรายการสินค้า
- ถ้าเชื่อมต่อไม่ได้ จะแสดงข้อมูลตัวอย่างต่อไป พร้อมแจ้งเตือน
- ตาราง `products` ใน schema ปัจจุบันไม่มีคอลัมน์ stock จึงแสดง “พร้อมจำหน่าย” แทนตัวเลขสต็อก
- เพิ่มระบบสมัครสมาชิก/เข้าสู่ระบบด้วยอีเมลและรหัสผ่านผ่าน Supabase Auth
- การสร้างบัญชีจะสร้างแถวใน `profiles` และ `customers` ได้เมื่อ trigger จากไฟล์ติดตั้งฐานข้อมูลทำงานอยู่
- ปุ่มยืนยันคำสั่งซื้อเรียก RPC `place_order` และจะล้างตะกร้าเมื่อบันทึกสำเร็จเท่านั้น
- รองรับการบันทึกไอศกรีมถัง พร้อมรสชาติ จำนวนถัง และอุปกรณ์เสริมที่เลือก
- หน้าติดตามแสดงคำสั่งซื้อและรายการสินค้าจากบัญชีลูกค้าที่เข้าสู่ระบบจริง ไม่ใช้ข้อมูลตัวอย่าง
- หน้าแต้มสะสมอ่านแต้มจาก `customers`; ยอดซื้อทุก 10 บาทได้ 1 แต้ม, ใช้ 100 แต้มแลกส่วนลด 50 บาท และแต้มหมดอายุ/รีเซ็ตเป็นรอบปีจากวันที่สร้างบัญชีลูกค้า

## ขั้นตอน
1. สำรองโฟลเดอร์ Ordering เดิมก่อน
2. นำไฟล์จาก ZIP นี้ไปแทนไฟล์ในโปรเจกต์เดิม โดยคงไฟล์ `.env.local` ของตัวเองไว้ ห้ามเขียนทับด้วยไฟล์ตัวอย่าง
3. ตรวจสอบว่า `.env.local` อยู่ระดับเดียวกับ `package.json` และมี:
   `VITE_SUPABASE_URL=https://<project-id>.supabase.co`
   `VITE_SUPABASE_ANON_KEY=<publishable-or-anon-key>`
4. ถ้าต้องการให้ผู้เยี่ยมชมที่ยังไม่ล็อกอินดูรายการสินค้าได้ ให้เปิด Supabase SQL Editor แล้วรัน `ordering_catalog_public_read.sql` ที่อยู่ใน ZIP นี้
5. เปิดไฟล์ `ordering_auth_order_patch.sql` แล้วรันใน Supabase SQL Editor หนึ่งครั้ง เพื่อเพิ่มโค้ดโปรโมชั่น, รองรับไอศกรีมถัง, เปิดสิทธิ์อ่านคำสั่งซื้อของเจ้าของบัญชี, และตั้งค่าระบบแต้มสะสม
6. จาก Terminal ในโฟลเดอร์โปรเจกต์ รัน `npm install` แล้ว `npm run dev`
7. เปิดเว็บไซต์ กด “เข้าสู่ระบบ” เพื่อสมัครบัญชีหรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน จากนั้นทดลองสั่งซื้อสินค้าถ้วยและ/หรือไอศกรีมถัง แล้วตรวจหน้าติดตามและแต้มสะสม

## ข้อควรรู้
- หากเปิด Email Confirmation ใน Supabase ระบบสมัครสมาชิกจะส่งอีเมลยืนยันก่อนเข้าสู่ระบบได้
- ต้องติดตั้ง schema พื้นฐานจาก `coconut_icecream_supabase_install.sql` ไว้ก่อน และ trigger `on_auth_user_created` ต้องทำงาน เพื่อสร้าง `profiles`/`customers` อัตโนมัติ
- การชำระเงินจริงยังไม่ได้เชื่อมกับผู้ให้บริการชำระเงิน; หน้านี้เพียงสร้างคำสั่งซื้อและบันทึกสถานะเริ่มต้นเป็น unpaid

## ความปลอดภัย
- ใช้เฉพาะ publishable key หรือ anon key ใน `.env.local` ของเว็บ
- ห้ามใช้ `service_role` หรือ secret key ฝั่ง browser
- ระบบแต้มจะคำนวณจากยอดสินค้าหลังหักส่วนลดทั้งหมด (รวมส่วนลดที่แลกด้วยแต้มถ้าเลือกใช้) โดยไม่รวมค่าจัดส่ง; RPC เป็นผู้คำนวณราคาและแต้มฝั่งฐานข้อมูล
- หน้า checkout แสดงแต้มที่คาดว่าจะได้รับตามยอดหลังหักส่วนลด และระบบจะไม่นำโค้ดโปรโมชันไปส่งหากยอดยังไม่ถึงขั้นต่ำ
